# ECG adaptive-security harness (partial scaffold)

Work-in-progress scaffold for the "Adaptive Security of ECG-Language Models"
proposal (v4). Only the stage-log contract, the config freezer, and the default
config exist so far. The pipeline wrapper, admissibility checker, attacks,
verifiers, and experiment runners are still to be written against the CARE-ECG
code in a session that has access to that repository.
